# Image Gallery with Search

This project is a simple **Image Gallery** created using **only HTML**.  
All styling and functionality are written directly inside the HTML file using inline **CSS** and **JavaScript**.

## 🚀 Features

- Responsive image gallery layout
- Search images by name
- Hover effect on image cards
- No external libraries or frameworks
- Single HTML file project

## 🛠️ Technologies Used

- HTML5 (with embedded CSS & JavaScript)

## 📂 Project Structure

project-folder/
│
├── index.html
└── README.md

## ▶️ How to Run

1. Download or clone the project
2. Open `index.html` in any modern web browser
3. Use the search box to filter images

## 📌 Notes

- This project does not require installation
- Works offline (images load from online source)
- Ideal for beginners learning HTML basics
